# LoopTodo Android 兼容矩阵

## 已完成的代码验证

- Android API 24–36 构建配置可解析，目标 SDK 36。
- arm64 Kotlin 原生锁机模块编译通过。
- 通知权限、通知监听、无障碍、电池优化、精确闹钟状态可实时读取。
- 锁机会话由前台服务保存并由 `BOOT_COMPLETED` 接收器恢复。
- 厂商后台设置入口对 Xiaomi/Redmi、OPPO/OnePlus/realme、vivo/iQOO、Huawei、Honor、Samsung 使用已知组件；组件不存在时回退应用详情页。

## 真机验收步骤

1. 开启通知、通知监听、精确闹钟，并按需开启无障碍增强约束。
2. 打开“厂商后台设置”，允许自启动、后台运行、后台弹出和电池无限制。
3. 启动 3 分钟锁机，验证 Home/Recent/通知下拉限制和紧急退出。
4. 启动锁机后重启设备，验证前台通知和锁机 Activity 恢复。
5. 创建 5 分钟后的强制触发规则，锁屏并清理后台，验证提醒、延迟和最终触发。
6. 关闭一项关键权限，验证应用能检测并阻止进入不满足条件的锁机。

## 风险声明

- 普通第三方应用无法获得 Device Owner 级别的绝对防卸载或绝对不可绕过能力。
- 厂商组件名和后台策略可能随系统升级变化，应用会安全回退到详情页，但仍需用户按设备说明完成设置。
- 当前开发环境无模拟器/真机，本矩阵中的“代码通过”不等于对应设备人工验收通过。
