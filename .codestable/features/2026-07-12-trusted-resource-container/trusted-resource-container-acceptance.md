# Trusted Resource Container 验收

- 用户可在开始专注前为任务批准网页、域名、本地视频和本地文件。
- 专注页只展示已批准资源，不能临时添加或删除。
- 受限浏览器拦截未批准跳转、新窗口、下载、非 HTTPS 和外部深链。
- 本地视频只播放应用内固定副本，不提供下载、全屏或画中画。
- 本地文件使用 SHA-256 审计指纹并在删除通行证时清理。
