# Mobile Polish Accessibility 设计
- 保持现有业务流程不变，集中改善小屏、字体放大、深色模式、动态效果与无障碍语义。
- 主页面和专注页面限制内容最大宽度，并在小于 360dp 时缩小安全边距。
- 主题跟随系统，状态栏同步明暗；全局文本允许系统字体缩放，最高倍率为 2。
- 系统开启减少动态效果时，关闭 HeroUI 动画。
- 导航标签、模式选择、联网策略和开关提供明确角色、选中状态或可访问标签。
- 本地恢复和操作失败使用可感知的加载、警告与实时播报状态。
